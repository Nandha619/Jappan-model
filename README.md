# NEWS STUDIO — 新聞スタジオ

தமிழ் செய்தி இதழ் வாசிப்பு செயலி (Mobile TV, PDF Paper, Gallery).

## அம்சங்கள்
- 📺 TV – இன்றைய செய்திகள் / Mobile TV
- 📰 Paper – PDF இதழ் (swipe / விளிம்பைத் தட்டி பக்கம் மாற்றலாம்)
- 🖼️ Gallery – படத்தொகுப்பு
- ⚙️ Settings – PDF, படங்கள் பதிவேற்றம்

## தரவு சேமிப்பு
PDF மற்றும் படங்கள் ஒவ்வொரு பயனரின் சாதனத்திலும் (IndexedDB) மட்டுமே சேமிக்கப்படும்.
